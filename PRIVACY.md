# Privacy Policy - RARK Shorts

RARK Shorts is a personal automation tool that uploads videos to its owner's own YouTube channel.

It uses Google sign-in only to upload videos and read basic channel details for the owner's account. It does not collect, store, sell or share data about any other person.

Access tokens are kept as encrypted GitHub Actions secrets and used only by this repository's workflows. Access can be revoked at any time at https://myaccount.google.com/permissions
